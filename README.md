## 📌 Sobre o Repositório

Este repositório reúne os meus estudos, exercícios de fixação e notebooks interativos focados no aprendizado da linguagem **Python**. 

O objetivo principal é consolidar a lógica de programação, sintaxe básica e manipulação de estruturas de dados através de desafios práticos do dia a dia.

---

## 🚀 Trilha de Aprendizado

| Módulo / Tópico | Conteúdo Prático | Arquivos Relacionados |
| :--- | :--- | :--- |
| **01. Fundamentos & Operadores** | Variáveis, tipos de dados e operadores matemáticos básicos. | `meuPrimeiroPrograma.py`<br>`operadoresMat.ipynb` |
| **02. Controle de Fluxo** | Estruturas condicionais (`if`, `elif`, `else`) e tomada de decisão. | `estruturasCondicionais.ipynb` |
| **03. Estruturas de Dados (Listas)** | Criação, manipulação, fatiamento e métodos de listas. | `listas.py`<br>`listas.ipynb` |
| **04. Estruturas de Dados (Dicionários)** | Mapeamento de dados baseados em pares chave-valor. | `Dicionario.ipynb` |
| **05. Desafios Práticos** | Resolução de problemas aplicados cobrindo os conceitos anteriores. | `Exercicio1.py` ao `Exercicio7.py` |
